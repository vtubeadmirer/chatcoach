# v0.1 초안에 대한 검토 의견 (2026-10-18 수신)

> 사용자가 v0.1 초안을 외부 검토자에게 보여 받은 의견을 그대로 옮긴 것이다. v0.2 개정의 입력 자료.

올려준 「치지직 방송 분석 — 라벨링 안내서 v0.1 초안」 확인했어.
현재까지 합의한 설계와 비교하면 기본 구조가 잘 잡혀 있어. 특히 AI 결과를 보지 않고 먼저 라벨링하는 원칙, 활동 구간을 채팅 반응과 독립적으로 판단하는 원칙, 반응이 없는 채팅을 무조건 놓친 채팅으로 취급하지 않는 기준이 잘 반영됐어.

다만 기준안으로 확정하기 전에 세 가지를 보완하는 게 좋아.

## 1. 실제 채팅과 가상 채팅의 출처 판정 추가

현재 문서에는 후원·시스템 메시지를 분리하는 기준은 있지만, 가상 채팅의 출처를 판정하는 단계는 없어.

다음 세 가지 값을 추가하는 게 좋겠어.

- `실제`: 실제 시청자가 작성한 채팅
- `가상`: 프로그램이 생성한 가상 채팅
- `판별 불가`: 둘 중 어느 것인지 확정할 수 없는 채팅

가상 채팅 생성 기록과 OCR 결과를 대조하고, 판별 불가 메시지는 실제 시청자 소통 통계에서 기본적으로 제외해야 해. 제외된 건수도 별도로 표시해야 하고.

## 2. 활동 구간에서 긴 침묵을 판단하는 기준 보완

문서에는 잡담 화면에서 2분 이상 침묵하면 기타 활동의 후보로 분류하는 기준이 있어.

그런데 스트리머가 생각하거나 잠시 쉬는 중이어도 여전히 저스트 채팅 구간일 수 있어. 침묵만으로 활동을 바꾸면 평가 대상 시간이 불필요하게 줄어들 수 있지.
따라서 긴 침묵은 재검토 신호로만 사용하고, 실제 활동이 바뀌었다는 근거가 있을 때 구간을 변경한다는 원칙을 추가하자.

## 3. 연결 등급과 확신도의 차이를 유지

이 부분은 현재 문서가 잘 정리하고 있어. 연결이 불명확하다는 판정과 사람이 판단 자체를 할 수 없다는 상태를 구분하고, 확신도가 낮은 결과를 엄격한 AI 성능 평가에서 제외하도록 되어 있어. 이 기준은 그대로 유지하면 돼.

## 결론

라벨링 안내서의 전체 구조를 다시 만들 필요는 없어. 기존 내용을 유지하면서 위 세 가지를 보완하면 돼.
그다음에는 문서에 적힌 시작값인 채팅 20초 이내 반응, 화면 노출 10초 이상, 경계 완충 10초 등을 실제 방송 샘플에서 검증하면 돼. 현재 문서도 이런 수치를 확정값이 아닌 시작값으로 정의하고 있어.
