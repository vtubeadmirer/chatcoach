## 0. 켜기 (처음 한 번)

```
cd C:\Users\dlem9\dev\chatcoach
.venv\Scripts\python main.py
```

1. **파일 → 프로젝트 열기** → 위 표의 폴더.
2. 세션 화면: 라벨러 `L01` → **1차 라벨링** → **열기**. 다음에 열면 **이어 하기** 가 골라져 있다.
3. 플레이어의 **영상 파일 연결…** → 같은 번호의 영상. (처음 한 번만)
4. **파일 → 프로젝트 백업…** 한 번.
5. 시작 시각을 적어 둔다 (걸린 시간을 잰다).

**하지 말 것:** '분석 보기' 세션을 열지 않는다. 엔진 판정을 보면 라벨이 쏠린다.

## ① 구간 (5분)

1. 모드 줄 **[① 구간]**.
2. 타임라인에서 20:00 으로 가서 `B`, 1:00:00 으로 가서 `B`. (휠 = 가로 이동, `Ctrl`+휠 = 확대)
3. 가운데 구간을 누르고 `Alt+J`(저스트채팅) → `Alt+1`(확실함) → 근거 칸에 한 줄(예: "토크만 함").
   - 중간에 게임 화면이 나오면 그 앞뒤에 `B` 를 더 두고 그 조각만 `Alt+G`.
4. `Ctrl+Enter` 저장 → **[구간 완료 표시]**.

20분 앞과 60분 뒤는 비워 둔다.

## ② 반응 (가장 오래 걸림)

20:00 부터 1:00:00 까지 **처음부터 끝까지** 본다. 스트리머가 채팅에 반응한 곳마다:

1. 오른쪽 채팅 표에서 그 채팅을 **더블클릭** (또는 고르고 `M`).
2. **[+ 후보 추가]** → 스트리머가 말을 시작할 때 **[시작=지금]**, 끝날 때 **[끝=지금]** → '들은 내용' 에 직접 들은 말을 적는다.
3. 증거를 체크한다.

   | 증거 | 무엇 |
   |---|---|
   | 강 | 닉네임을 부름 / 채팅을 읽거나 거의 그대로 말함 / "방금 질문" 처럼 채팅을 가리킴 |
   | 중 | 질문에 맞는 답 / 채팅에만 있던 구체적 내용이 말에 나옴 / 채팅 뒤 20초 안 |
   | 약 | 주제만 같음 |

4. 등급: 아래에 '고를 수 있는 등급' 이 표시된다.

   | 키 | 등급 | 언제 |
   |---|---|---|
   | `Ctrl+1` | 직접 반응 | 강한 증거가 하나라도 있음 |
   | `Ctrl+2` | 연결 가능성 높음 | 강 없음 + 중 2개 이상 + 비슷한 다른 채팅 없음 |
   | `Ctrl+3` | 관련성만 있음 | 주제만 같거나, 이미 그 얘기를 하던 중 |
   | `Ctrl+4` | 불명확 | 후보는 있는데 어느 채팅인지 못 가림 |

5. 확신도 `Alt+1` 확실함 · `Alt+2` 아마도 · `Alt+3` 판단 불가 → 근거 칸에서 `Ctrl+T` 로 시각을 넣고 한 줄.
6. 직접·높음이면 `R` 로 그 장면을 **두 번** 끝까지 듣는다(2배속까지 됨).
7. (선택) 이어짐: 한두 마디로 끝남 / 1분 미만 / 1분 이상 또는 채팅 3개 이상 이어짐 / 새 주제로 바뀜.
8. `Ctrl+Enter` 저장. 잘못 저장했으면 `Ctrl+Z`.

다 봤으면 **[반응 완료 표시]**.

이동: `Space` 재생 · `J`/`L` ±5초 · `Shift+←/→` ±1초 · `←/→` 1프레임.

## ③ 표본 (무작위 100건)

1. **[③ 표본]** → **[표본 뽑기]** → **[재현 검증]**.
2. 한 건씩 그 채팅 주변이 반복 재생된다.
   - 반응이 없으면: `Alt+1` → 근거 한 줄 → `Ctrl+5`(반응 미확인).
   - 반응이 있으면: `M` → ② 와 같은 방법.
   - 소리로 판단이 안 되면 **[판단 불가로 저장]**.
3. `PgDown` 다음 · `PgUp` 이전. 이미 ② 에서 매긴 채팅은 '판정함' 으로 넘어간다.
4. 100건을 다 하면 **[표본 완료 표시]**.

## 끝내기

1. **파일 → 라벨 내보내기…** (기본 위치 그대로 저장).
2. **세션 → 이 세션 잠그기…** → 요약 확인 → 두 번 확인. **잠그면 고칠 수 없다.**
3. 끝난 시각을 적는다. 걸린 시간을 Claude 에게 알려 준다.

한 번에 다 하지 않아도 된다. 창을 닫으면 저장된 것은 남고, 다음에 **이어 하기** 로 연다. 잠그기만 마지막에 한다.
