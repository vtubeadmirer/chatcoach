# 시범 라벨링 하는 법

## 이게 뭐 하는 일인가

방송을 보면서 **"스트리머가 어떤 채팅을 보고 대답했는지"** 를 표시하는 일입니다.

예를 들어 시청자가 `오늘 뭐 먹었어요?` 라고 쓰고, 몇 초 뒤 스트리머가 "오늘 떡볶이 먹었어요" 라고 말했다면, 그 채팅에 "반응했다" 고 표시합니다.

이렇게 사람이 표시한 것이 **정답지**가 됩니다. 나중에 프로그램이 스스로 찾은 결과를 이 정답지와 비교해 채점합니다.

## 매길 범위

| 방송 | 매길 범위 |
|---|---|
| ① VOD 15663452 | 영상 시각 **20:00 ~ 1:00:00** |
| ② VOD 15652997 | 영상 시각 **20:00 ~ 1:00:00** |
| ③ VOD 15491104 | 영상 시각 **20:00 ~ 1:00:00** |

한 편에 40분씩입니다. 그 밖의 시간은 보지 않아도 됩니다.

## 큰 순서 (한 편마다)

| 단계 | 하는 일 | 걸리는 시간 |
|---|---|---|
| 준비 | 앱 켜고 프로젝트 열기 | 1분 |
| ① 구간 | "20분~60분은 토크 방송" 이라고 표시 | 2분 |
| ② 반응 | 40분을 보면서, 스트리머가 채팅에 대답할 때마다 표시 | 2~3시간 |
| ③ 표본 | 앱이 아무렇게나 고른 채팅 100개에 "대답했나, 안 했나" 답하기 | 1시간 |
| 끝내기 | 내보내기, 잠그기 | 1분 |

한 번에 다 안 해도 됩니다. 창을 닫아도 저장한 것은 남습니다.

### 영상 다루기

영상 바로 아래 단추 줄로 합니다. 단추 위에 마우스를 올리면 단축키가 보입니다.

| 단추 | 하는 일 | 단축키 |
|---|---|---|
| ▶ 재생 / ⏸ 일시정지 | 재생·멈춤 | `Space` |
| −10초 / +10초 | 10초 뒤로·앞으로 | `Ctrl+←` / `Ctrl+→` |
| −5초 / +5초 | 5초 뒤로·앞으로 | `J` / `L` |
| −1초 / +1초 | 1초 뒤로·앞으로 | `Shift+←` / `Shift+→` |
| ◀\| / \|▶ | 한 장면씩 | `←` / `→` |
| 느리게 / 빠르게 | 재생 속도 | `[` / `]` |

- 아래 **타임라인**(시간 눈금 막대)을 누르면 그 시각으로 갑니다.
- 영상 화면을 눌러도 재생·멈춤이 됩니다.
- 단축키가 안 먹으면: 글자 칸(검색칸·근거칸)에 커서가 있는 것입니다. 타임라인을 한 번 누르세요.

## ① 구간 — "이 40분은 토크 방송" 표시하기

1. 위쪽 **[① 구간]** 을 누릅니다. 오른쪽이 '활동 구간' 화면으로 바뀝니다.
2. 타임라인에서 **20:00** 을 누르고, 오른쪽 **[지금 위치에서 쪼개기 (B)]** 를 누릅니다.
3. 타임라인에서 **1:00:00** 을 누르고, 다시 **[지금 위치에서 쪼개기 (B)]** 를 누릅니다.
   - 몇 초 어긋나도 괜찮습니다.
4. 타임라인에서 **20분과 60분 사이**를 한 번 누릅니다. 오른쪽 위에 '구간 2/3 · 00:20:… ~ 01:00:…' 이 보이면 맞습니다.
5. **[저스트채팅]** 을 누릅니다.
6. **[확실함]** 을 누릅니다.
7. '근거 한 줄' 칸에 `토크만 함` 이라고 적습니다.
8. **[저장 Ctrl+Enter]** 를 누릅니다.
9. 위쪽 **[구간 완료 표시]** 를 누릅니다.

앞(0~20분)과 뒤(60분~)는 손대지 않고 '미분류' 로 둡니다.

> 20~60분 사이에 게임 화면이 길게 나오면, 그 시작과 끝에서도 '쪼개기' 를 하고 그 조각만 **[게임]** 으로 표시합니다. 토크만 있었다면 신경 쓰지 마세요.

## ② 반응 — 스트리머가 채팅에 대답한 곳 표시하기

**대부분은 채팅 두 번 클릭 → Enter 로 끝납니다.**

1. 위쪽 **[② 반응]** 을 누릅니다. 오른쪽에 채팅 목록이 보입니다.
2. 타임라인에서 **20:00** 을 누르고 **▶ 재생**.
3. 스트리머가 채팅에 대답하면 **⏸ 멈춥니다.** 멈춘 곳이 '대답한 때' 로 저장됩니다.
4. 오른쪽 목록에서 **그 채팅을 두 번 누릅니다.** (위쪽 검색칸에 채팅 글자 일부를 넣어 찾아도 됩니다.)
5. 단추 6개가 뜹니다. **어떻게 대답했는지 하나만 누릅니다.** 누르면 바로 저장되고 닫힙니다.
   - 채팅을 읽고 대답했으면 그냥 **Enter**. (파란 테두리 단추가 Enter 입니다.)

| 단추 | 이럴 때 | 단축키 |
|---|---|---|
| **1. 닉네임 부르고 대답** | "○○님~" 하고 이름을 부르며 대답 | `Ctrl+Shift+1` |
| **2. 채팅 읽고 대답** | 채팅을 소리 내 읽고 대답 | **`Enter`** 또는 `Ctrl+Shift+2` |
| **3. 채팅 가리키고 대답** | "방금 질문", "아까 그거" 처럼 채팅을 가리키며 대답 | `Ctrl+Shift+3` |
| **4. 질문에 대답** | 이름도 안 부르고 읽지도 않았지만, 그 질문에 맞는 답을 함 | `Ctrl+Shift+4` |
| **5. 주제만 같음** | 같은 이야기지만 그 채팅에 대답한 건지는 모르겠음 | `Ctrl+Shift+5` |
| **6. 어느 채팅인지 모름** | 대답은 했는데 어느 채팅에 한 건지 모르겠음 | `Ctrl+Shift+6` |

- 대답이 아니었으면 **[취소]** 나 **Esc**. 아무것도 저장되지 않습니다.
- **이미 표시한 채팅은 초록색**이고 '종류' 칸에 `✓ 직접` 처럼 나옵니다. 앱을 껐다 켜도 그대로입니다. 초록 채팅을 두 번 누르면 새로 만들지 않고 그 표시를 고칩니다.
- 저장되면 아래 상태 줄에 `저장: 직접 반응 (채팅 읽고 대답)` 처럼 나옵니다. 다시 **▶ 재생** 해서 이어 봅니다.
- 등급·확신도·근거는 앱이 정해서 넣습니다. 따로 고를 것이 없습니다.
- '4. 질문에 대답' 은 보통 '관련성만 있음' 으로 저장됩니다. 비슷한 다른 채팅이 없다고 표시해 두었을 때만 더 높게 저장됩니다.
- 두 번 듣기는 **안 해도 됩니다.** 하면 더 좋습니다. 안 하면 타임라인에 속이 빈 표시로 남을 뿐입니다.
- 저장이 안 되면 빨간 글씨로 이유가 한 줄 나오고 아래 '자세히 입력' 이 펼쳐집니다. 거기서 고치고 **Ctrl+Enter**.

1:00:00 까지 다 보면 위쪽 **[반응 완료 표시]** 를 누릅니다.

### 자세히 입력 (애매할 때만)

단추 아래 **[자세히 입력 ▸]** 를 누르면 예전 화면이 펼쳐집니다. 펼쳐 두면 다음에도 펼쳐진 채로 열립니다. 빠른 단추로 저장한 것도 그 채팅을 다시 두 번 누르면 여기서 고칠 수 있습니다.

| 칸 | 할 일 |
|---|---|
| **[+ 후보 추가]** | 누릅니다 |
| **[시작=지금]** | 스트리머가 그 대답을 **말하기 시작한 순간**에 맞춰 누릅니다 (−1초·+1초 단추로 맞추고 누르기) |
| **[끝=지금]** | 대답이 **끝난 순간**에 누릅니다 |
| **들은 내용** | 스트리머가 한 말을 대충 적습니다. 예: `떡볶이 먹었다고 함` |
| **증거 체크** | 아래 표에서 맞는 것을 모두 체크 |
| **연결 발화** | 방금 만든 후보를 고릅니다 |
| **등급** | 아래 '등급 고르는 법' 대로 |
| **확신도** | 확실하면 **확실함**, 좀 애매하면 **아마도** |
| **근거** | **[현재 시각 (Ctrl+T)]** 를 누르고 한 줄. 예: `닉네임 부르고 대답함` |

- 시간이 되면 **[7-2 범위 다시 듣기 (R)]** 로 그 장면을 두 번 들어도 좋습니다. (권장. 안 해도 저장됩니다.)
- 다 채우면 **[저장 (Ctrl+Enter)]**. 이 화면의 글자 칸에서는 Enter 가 저장이 아닙니다.

### 증거 체크 — 무엇을 들었나

| 체크 칸 | 이럴 때 체크 |
|---|---|
| **닉네임 호명** | 스트리머가 그 시청자 닉네임을 불렀다 ("○○님~") |
| **문구 되풀이** | 채팅 글을 소리 내 읽었거나 거의 그대로 따라 말했다 |
| **직접 가리킴** | "방금 질문", "아까 물어보신 거" 처럼 채팅을 가리켰다 |
| **질문에 맞는 답** | 채팅이 질문이었고, 그 질문에 맞는 대답을 했다 |
| **채팅에만 있던 내용** | 채팅에서 처음 나온 구체적인 단어·이야기가 스트리머 말에 나왔다 |
| **같은 주제** | 이야기 주제만 같다 |

('시간 창 안' 은 앱이 시각을 보고 알아서 채웁니다.)

### 등급 고르는 법

위에서부터 차례로 보고, 처음 "예" 인 것을 고릅니다.

| 질문 | 예이면 |
|---|---|
| 닉네임을 불렀거나, 채팅을 읽었거나, 채팅을 직접 가리켰나? | **직접 반응** (`Ctrl+1`) |
| 위는 아니지만, 질문에 맞는 답 + 채팅에만 있던 내용(또는 20초 안) 처럼 증거가 2개 이상이고, 비슷한 다른 채팅이 없나? | **연결 가능성 높음** (`Ctrl+2`) |
| 주제만 같거나, 스트리머가 이미 그 얘기를 하던 중이었나? | **관련성만 있음** (`Ctrl+3`) |
| 비슷한 채팅이 여러 개라 어느 채팅에 대답한 건지 모르겠나? | **불명확** (`Ctrl+4`) |

- 앱이 '고를 수 있는 등급' 을 보여 줍니다. 그 밖의 등급을 고르면 이유를 한 줄 더 적어야 합니다.
- 직접 반응은 닉네임·읽기·가리킴 중 하나가 꼭 체크돼 있어야 저장됩니다.
- **헷갈리면 낮은 등급**을 고르고 확신도를 **아마도** 로 하세요.

### 표시하지 않아도 되는 것

- 스트리머가 채팅과 상관없이 혼자 하는 말
- 후원 알림을 읽는 것 (후원 채팅은 따로 셉니다)
- 이모티콘만 있는 채팅 (`{:799:}` 같은 글자) — 스트리머가 그걸 보고 반응했으면 표시해도 됩니다

## ③ 표본 — 아무렇게나 고른 채팅 100개 확인하기

②는 "눈에 띈 대답" 만 모읍니다. 놓친 게 얼마나 되는지 알려고, 앱이 채팅 100개를 무작위로 골라 하나씩 묻습니다.

1. 위쪽 **[③ 표본]** 을 누르고 **[표본 뽑기]** 를 누릅니다.
2. **[재현 검증]** 을 한 번 누릅니다. (뽑기가 제대로 됐는지 확인하는 단추입니다. '통과' 가 나오면 됩니다.)
3. 채팅 하나가 나오고, 그 채팅 앞뒤 영상이 자동으로 반복 재생됩니다. 듣고 판단합니다.

| 스트리머가 그 채팅에 | 할 일 |
|---|---|
| **대답 안 했다** | **[반응 미확인 저장 Ctrl+5]** 하나만 누릅니다. (확실함 · `대답 없음` 은 앱이 넣습니다) |
| **대답했다** | 대답을 듣고 멈춘 뒤 **M** (또는 **[반응 있음 → 편집기 M]**) → ② 와 같은 단추 6개 중 하나. 채팅을 읽고 대답했으면 **Enter** |
| **소리가 안 들려서 모르겠다** | **[판단 불가로 저장]** 하나만 누릅니다 |
| 이미 ②에서 표시한 채팅 | '판정함' 으로 넘어갑니다. 할 일 없음 |

4. **[다음 ▶ PgDown]** 으로 다음 채팅. 100개를 다 하면 **[표본 완료 표시]**.

## 시범이 끝나면

세 편 모두 처음 매기기와 7일 뒤 다시 매기기까지 마치고 **잠그기**를 했으면, Claude 와의 채팅에 **"시범 세션 모두 잠금"** 이라고 한 줄만 적어 주세요. 누를 것은 없습니다. 그러면 Claude 가 잠금이 다 됐는지 확인하고, 프로그램 답과 정답지를 견줄 준비를 한 뒤 숫자를 보여 드립니다. 이 견주기는 한 번 열면 되돌릴 수 없어서, 숫자를 보신 뒤 채팅으로 **"시작"** 이라고 한 번 더 적어 주셔야 시작합니다. 그전까지 Claude 는 시범 방송 폴더를 열지 않습니다. 하나라도 덜 잠겼으면 무엇이 남았는지만 알려 드리고 멈춥니다.

## 해제 뒤: AI 확인 큐

견주기를 연 뒤에는, 프로그램이 "대답했다" 고 했는데 **정답지에 표시가 없는 채팅**이 몇십 개 남습니다. 사람이 그 채팅만 하나씩 보고 "정말 대답했나" 를 답하면, 프로그램이 얼마나 정확한지(정밀도)가 확정됩니다. 한 편에 20개쯤, 하나에 몇 초면 됩니다.

1. **AI 확인 큐** 아이콘을 두 번 누릅니다. (Claude 가 만들어 둔 바로 가기입니다. 원래 쓰던 ChatCoach 아이콘은 그대로입니다.)
2. 앱이 시범 방송을 **분석 보기**로 열고, '엔진과 나란히 보기' 창을 **AI 확인 큐** 로 띄웁니다. 첫 채팅의 앞뒤(채팅 5초 전 ~ 대답 3초 뒤)가 자동으로 반복 재생됩니다. 누를 것은 없습니다.
3. 듣고 숫자 키 하나를 누릅니다. 한/영 상태와 상관없이 됩니다.

| 들어 보니 | 누를 것 |
|---|---|
| 스트리머가 그 채팅에 **대답했다** | **1** (반응 맞음) |
| **대답한 게 아니다** | **2** (아님) |
| 소리가 안 들리거나 **모르겠다** | **3** (모름) |

4. 누르면 저장되고 **다음 채팅으로 저절로 넘어가** 다시 반복 재생됩니다. 창 아래 '진행 n / 전체' 가 다 차면 끝입니다. 창을 닫으면 반복이 멈춥니다.

- 잘못 눌렀으면 목록에서 그 줄을 누르고 맞는 숫자를 다시 누르면 됩니다(마지막에 누른 것이 남습니다).
- 프로그램 판이 둘(v0.2·v0.3)이면 창 맨 위 '엔진 판' 을 바꿔 한 번 더 합니다. 판마다 따로 셉니다.
- 나란히 보기·작업대 엔진 띠의 **흐린(속 빈 회색) 점은 likely**(프로그램이 '아마 대답' 이라고 한 것)입니다. 기본은 direct 만 대답으로 세고, 'likely 도 반응으로 보기' 를 켜면 둘 다 셉니다. AI 확인 큐에는 둘 다 나옵니다.
- 다 했으면 Claude 에게 "확인 큐 끝" 이라고 적어 주세요. 숫자를 정리해 드립니다.
- 시범 세션이 다 잠기고 견주기를 열기 전에는 이 창이 열리지 않습니다(상태 줄에 까닭 한 줄만 나옵니다).

(Claude 용: 아이콘이 하는 일은 `ChatCoach.exe --project <시범 프로젝트 폴더> --analysis --confirm`, 개발 PC 에서는 `.venv\Scripts\pythonw main.py --project <폴더> --analysis --confirm` 입니다.)
