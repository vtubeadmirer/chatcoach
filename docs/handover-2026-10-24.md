## 3. 작업 규칙 (사용자가 정한 것, 그대로 지킬 것)

1. **결정은 모델이 정하고 D-xx 로 기록한 뒤 쭉 진행**한다. 사용자에게 묻는 일은 최소. 되돌릴 수 없는 일(봉인 해제, 삭제, 외부 공개)만 숫자를 보이고 확인을 받는다.
2. **클릭 한 번(D-16).** 사용자에게 명령어 붙여넣기·긴 폼을 시키지 않는다. 넘기기 전에 모델이 직접 돌려 재 본다(스크린샷은 PowerShell 로 주 모니터 캡처 → 이미지로 봄; 모니터 3개, 주 모니터 1920×1080).
3. **개인정보·블라인드.** 실제 채팅 본문·닉네임·userIdHash·전사문은 저장소·시험·로그·보고서·대화에 절대 넣지 않는다(숫자·해시만, 시험 예문은 합성값 — `tests/test_fixture_clean.py` 가 잡는다). 외부 AI·서비스로 사용자 데이터를 보내지 않는다(LM Studio 는 127.0.0.1 만, 서버는 사용자가 켠다 — `lms server start` 금지). 삭제는 휴지통으로, 단 시범 전사·음성 중간 파일(`chatcoach-data\sealed-work`)은 `Remove-Item`/`os.remove`.
4. **시범 고정.** `schemas/label-event.schema.json` 과 `assets/guide-config.v0.1.json` 은 다음 시범 편을 열기 전까지 고정(`tools/pilot_freeze.py --check` 통과). 시범 프로젝트 폴더 `chatcoach-data\projects\pilot-*` 에는 쓰지 않는다. 봉인된 엔진 결과는 그 편의 라벨링 세션이 잠긴 뒤에만 푼다(`tools/pilot_unseal_day.py`).
5. **커밋.** 메시지 끝에 `Co-Authored-By: <모델 이름> <noreply@anthropic.com>`. 에이전트(하위 작업자)는 커밋·푸시하지 않고 메인 세션이 검증 뒤 한다. 서명 키(`%LOCALAPPDATA%\ChatCoach-signing`)는 출력·커밋 금지.
6. **보고는 쉬운 한국어, 숫자만.** 시각은 플레이어 형식(HH:MM:SS). 모델 배분(판단·심사는 상위 모델, 구현·조사·문서는 실행 모델)을 표로 함께 적는다.
7. 환경 함정: bash heredoc 은 백슬래시를 먹는다(파일은 Write/Edit 로), bash 에서 `"C:\…\$p"` 는 `$p` 가 사라짐(작은따옴표나 `/` 경로), Acronis Active Protection 이 python.exe 를 멈추면 앱·스모크가 '응답 없음' 처럼 보임(사용자가 신뢰 목록에 넣어야 함), `tests/test_smoke_watch.py` 는 부하 때만 실패.
