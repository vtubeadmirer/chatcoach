# 챗코치 설치·업데이트·백업 안내

이 문서는 챗코치를 쓰는 분을 위한 안내입니다. 받기, 풀기, 첫 실행, 업데이트, 되돌리기, 백업, 지우기 순서로 적었습니다.

> 메뉴 이름은 앱의 판에 따라 조금 다를 수 있습니다. 메뉴가 안 보이면 이 문서 맨 아래의 '문제가 생기면' 을 보세요.

---

## 1. 받기

1. 릴리스 페이지(`https://github.com/vtubeadmirer/chatcoach/releases/latest`)를 엽니다.
2. `ChatCoach-vX.Y.Z-win64.zip` 을 받습니다. (`X.Y.Z` 는 버전 번호입니다.)
3. 받은 zip 파일을 오른쪽 클릭 → **속성** → 아래쪽 **차단 해제** 에 체크 → **확인**.
   풀기 **전에** 해야 합니다. 그래야 Windows 가 안의 프로그램을 '인터넷에서 받은 파일' 로 계속 의심하지 않습니다.

받은 파일이 맞는지 확인하고 싶으면(선택) PowerShell 에서 아래를 실행하고, 같은 릴리스의 `SHA256SUMS` 파일에 적힌 값과 비교합니다.

```powershell
(Get-FileHash .\ChatCoach-vX.Y.Z-win64.zip -Algorithm SHA256).Hash.ToLower()
```

## 2. 풀기 — 어디에 둘까

**권장 위치: `%LOCALAPPDATA%\Programs\ChatCoach`**

탐색기 주소창에 `%LOCALAPPDATA%\Programs` 를 붙여 넣고 Enter 를 누르면 그 폴더가 열립니다. 거기에 zip 을 풀면 `ChatCoach` 폴더가 생깁니다.

이 위치를 권하는 이유:

- **OneDrive 밖입니다.** 바탕 화면·문서 폴더는 OneDrive 와 동기화되는 경우가 많습니다. 그 아래에 두면 채팅과 라벨이 클라우드로 올라가고, 동기화가 파일을 붙잡아 저장이 실패하거나, 지운 뒤에도 OneDrive 휴지통·버전 기록에 사본이 남습니다.
- **관리자 권한이 필요 없습니다.** `C:\Program Files` 는 쓰기가 막혀 있어 자동 업데이트가 되지 않습니다.
- **경로가 짧습니다.** 경로가 너무 길면(앱 폴더 120자, 프로젝트 폴더 180자 넘게) 저장이 실패할 수 있습니다.

피할 곳:

| 위치 | 문제 |
|---|---|
| 바탕 화면, 문서, `OneDrive` 가 들어간 폴더 | 클라우드 업로드·동기화 충돌 |
| `\\서버\공유` 같은 네트워크 폴더 | 동시 저장·잠금을 믿을 수 없고, 자동 업데이트와 휴지통이 동작하지 않음 |
| `C:\Program Files` | 쓸 수 없어 데이터가 다른 곳(`%LOCALAPPDATA%\ChatCoach\data`)으로 가고 자동 업데이트가 꺼짐 |
| USB 메모리 | 빼면 저장이 끊기고, 지울 때 휴지통을 거치지 않음 |

폴더 이름에 한글이 있어도 대부분 괜찮습니다. 영상 열기나 업데이트가 이상하면 영문 이름 폴더로 옮겨 보세요.

앱을 켤 때와 프로젝트를 열 때 위치를 점검합니다. OneDrive·네트워크 폴더면 **'옮기기 권장 / 그래도 계속'** 을 묻습니다. 가능하면 옮기세요.

## 3. 첫 실행

1. `ChatCoach` 폴더 안의 `ChatCoach.exe` 를 더블클릭합니다.
2. 처음에는 Windows 가 **'Windows의 PC 보호'** 창을 띄울 수 있습니다. 코드 서명 인증서가 없는 작은 프로그램이라 그렇습니다. **추가 정보** → **실행** 을 누릅니다. 앱 안 업데이트 뒤에는 보통 다시 뜨지 않습니다.
3. 회사 PC 에서 실행 자체가 막히면(Smart App Control, AppLocker 등) 회사 IT 담당에게 예외를 요청해야 합니다.

### 내 기록은 어디에 있나

| 무엇 | 위치 |
|---|---|
| 프로젝트·설정·로그 (내 작업 전부) | `ChatCoach\data\` (앱 폴더 안) |
| 자동 백업 | `%LOCALAPPDATA%\ChatCoach\backups\` (앱 폴더 밖) |

앱 폴더를 통째로 다른 곳에 복사하면 작업도 따라갑니다. 단, 자동 백업은 앱 폴더 밖에 있어 따라가지 않습니다(옛 앱 폴더를 지워도 백업이 남게 하려고 일부러 밖에 둡니다).

## 4. 업데이트

**앱 안에서 하는 것이 기본입니다.**

1. 새 버전이 나오면 창 아래쪽에 알림이 뜹니다.
2. **업데이트** 를 누르면 받기 → 확인 → 교체 → 다시 켜기까지 자동으로 합니다.
3. 교체하기 직전에 라벨·설정을 `%LOCALAPPDATA%\ChatCoach\backups\pre-update\` 에 따로 백업합니다(최근 5개).

업데이트해도 `data\` 폴더(내 기록)는 그대로입니다.

### 앱 안 업데이트가 안 될 때 (손으로 하기)

1. 앱을 끕니다.
2. 1장처럼 새 zip 을 받고 **차단 해제** 합니다.
3. **새 폴더**에 풉니다. 예: `%LOCALAPPDATA%\Programs\ChatCoach-new\`
4. 옛 폴더의 `data\` 폴더를 새 폴더의 `ChatCoach\` 안으로 **복사**합니다.
5. 새 `ChatCoach.exe` 를 실행해 버전과 프로젝트 목록을 확인합니다.
6. 괜찮으면 옛 폴더를 지우고 새 폴더 이름을 원래대로 바꿉니다.

옛 폴더 위에 그대로 덮어 풀지 마세요. 새 버전에서 없어진 파일이 남아 섞일 수 있습니다. 꼭 덮어써야 하면 옛 `ChatCoach.exe` 와 `_internal\` 만 먼저 지우고 풉니다. **`data\` 는 지우지 마세요.**

### (고급) 받은 파일이 정말 개발자 것인지 확인

`latest.json` 과 `latest.json.minisig` 를 받아 [minisign](https://jedisct1.github.io/minisign/) 으로 서명을 확인한 뒤, `latest.json` 안의 `sha256` 과 zip 의 해시를 비교합니다.

```powershell
minisign -Vm latest.json -P RWRcyUF44YPa8Bfo4jqfCXr/dSMQlH853FAHFR5U58miyChvUp/iC0gp
```

공개키는 두 개입니다. 위 것(K1)으로 실패하면 예비 키(K2)로도 해 봅니다.

- K1 (운용): `RWRcyUF44YPa8Bfo4jqfCXr/dSMQlH853FAHFR5U58miyChvUp/iC0gp`
- K2 (예비): `RWSPEWr57suXcry8hkMgzUrqbh2tgeod3EiIJ/YGKa1NbwwrG0QA5B5u`

앱 안 업데이트는 이 확인을 자동으로 하고, 서명이 맞지 않으면 설치하지 않습니다.

## 5. 되돌리기 (이전 버전으로)

새 버전이 켜지기는 하는데 라벨링이 이상하면 이전 버전으로 돌아갈 수 있습니다.

- **도움말 → 이전 버전으로 되돌리기…** 를 누릅니다. 되돌릴 수 없을 때는 메뉴가 꺼져 있고, 마우스를 올리면 까닭이 보입니다.
- 업데이트 직후 앱이 연달아 비정상으로 꺼지거나, 업데이트가 중간에 멈췄거나 복구까지 실패하면, 다음에 켤 때 앱이 먼저 되돌리기(또는 같은 버전 사본으로 '복구')를 권합니다.
- 되돌리기 전에 이전 사본이 이 PC 에서 실행되는지 먼저 점검하고(최대 90초), 라벨·설정 백업을 한 번 더 만듭니다.
- 업데이트할 때 남겨 둔 이전 프로그램 사본(`ChatCoach\_backup\`)을 씁니다. 이 사본은 새 버전이 **한 번 정상으로 꺼진 뒤** 다음 시작에서 지워집니다. 그래서 되돌리기 메뉴는 **업데이트 직후 실행에서만** 켜집니다. 그 뒤에는 4장의 '손으로 하기' 로 옛 버전 zip 을 받아 설치해야 합니다.
- 되돌린 버전은 다시 권하지 않습니다. 더 새 수정 버전이 나오면 그때 다시 알립니다.
- 라벨은 지워지지 않습니다. 다만 새 버전에서 처음 만든 형식의 줄은 옛 버전에서 '읽기 전용' 으로 보일 수 있습니다.

## 6. 백업

### 자동 백업

- **하루 한 번**, 모든 프로젝트의 라벨·표본·잠금·프로젝트 정보를 `%LOCALAPPDATA%\ChatCoach\backups\<프로젝트 번호>\` 에 zip 으로 남깁니다.
- 채팅(가린 닉네임과 본문)은 **일주일에 한 번** 함께 넣습니다.
- 프로젝트마다 **최근 14개**만 남기고, 오래된 것은 **휴지통**으로 보냅니다.
- 세션을 마칠 때 그 세션 기록 파일 하나를 같은 곳의 `sessions\` 에 복사합니다.

### 직접 백업 만들기

**파일 → 프로젝트 백업…** 으로 지금 바로 zip 을 만들 수 있습니다(연 프로젝트가 없으면 폴더를 고릅니다).

- 기본으로 라벨과 채팅이 들어갑니다.
- **원 닉네임·시청자 식별값(보호 구역)은 기본으로 빠집니다.** 꼭 필요할 때만 '보호 포함' 을 켜세요. 켜면 그 zip 은 **다른 사람에게 보내면 안 되는** 파일이 되고, OneDrive·네트워크 폴더에는 저장할 수 없습니다.
- 저장 위치로 프로젝트 폴더 안, 앱의 `data\` 폴더 안, 앱 폴더 안은 고를 수 없습니다(앱 폴더를 지우면 함께 사라지기 때문).
- 다른 PC·외장 드라이브에 사본을 두려면 이 zip 을 직접 옮기세요.

### 백업에서 되살리기

**파일 → 백업에서 되살리기…** 로 zip 을 고르고 풀 폴더를 고릅니다.

- 항상 **새 폴더**로 풉니다. 있는 폴더를 덮어쓰지 않습니다. 같은 이름이 있으면 `…-restored-<날짜>` 로 풉니다.
- 같은 프로젝트가 둘이 되므로, **원본이 망가지거나 없어졌을 때만** 쓰세요. 둘 다 계속 쓰면 기록이 갈라집니다.
- 풀기 전에 zip 안 파일이 만들 때와 같은지(크기·해시) 확인합니다. 다르면 풀지 않습니다.

업데이트 직전 백업(`pre-update\`)은 여러 프로젝트가 한 zip 에 들어 있어 이 메뉴로 풀지 않습니다. 필요하면 zip 을 열어 해당 프로젝트 폴더의 파일만 꺼내세요.

## 7. 지우기

### 보존 기한

프로젝트마다 보존 기한이 있습니다(처음 만들 때 **만든 날 + 12개월**). 기한이 30일 안으로 다가오거나 지나면 프로젝트를 열 때 알려 줍니다. 목적을 이뤘으면 파기하세요.

### 프로젝트 지우기 (파기)

**파일 → 프로젝트 지우기(휴지통)…** 를 누르면, 무엇을 지울지 목록을 먼저 보여 주고 확인(확인 칸 + 라벨러 코드)을 받은 뒤 **휴지통으로** 보냅니다. 지금 연 프로젝트면 앱이 먼저 닫고 보냅니다. 다른 창·PC 가 열고 있으면 거부합니다.

함께 지우는 것:

- 프로젝트 폴더 (채팅·라벨·보호 구역 전부)
- 그 프로젝트의 자동·직접 백업 (`%LOCALAPPDATA%\ChatCoach\backups\<프로젝트 번호>\`)
- 앱 `data\` 안의 그 프로젝트 몫: 채팅 색인 캐시, 영상 파형·썸네일 캐시, AI 결과, 일치도 보고서

**'라벨만 남기기'** 를 고르면 채팅(본문·닉네임)·보호 구역·파생 파일만 지우고 라벨·표본·프로젝트 정보는 남깁니다. 라벨의 근거·메모에 닉네임을 직접 적었다면 그 내용은 남으니 주의하세요.

꼭 알아 둘 것:

- **지운 것은 휴지통으로 갑니다.** 실수로 지웠으면 휴지통에서 되살릴 수 있습니다. 디스크에서 완전히 없애려면 **휴지통을 비우세요.**
- 네트워크 폴더·USB 처럼 휴지통이 없는 곳의 파일은 지우지 않고 남깁니다. 목록에 따로 표시하니 직접 지우세요.
- 파기 기록이 `data\disposal_log.jsonl` 에 남습니다(프로젝트 번호, 시각, 지운 위치, 실행한 라벨러 코드만. 채팅 내용은 없습니다).
- **이 명령이 지울 수 없는 사본:** OneDrive 의 휴지통·버전 기록, 다른 PC, 공유 드라이브, 다른 사람에게 보낸 zip, 직접 다른 곳에 옮긴 백업. 이런 사본은 각각 직접 지워야 합니다.
- 업데이트 직전 백업(`pre-update\`)에는 여러 프로젝트의 라벨이 한 파일로 들어 있어 파기 때 남깁니다. 최근 5개만 남고 업데이트할 때마다 밀려납니다.

### 앱을 완전히 지우기

1. 필요한 프로젝트를 먼저 파기하거나 백업을 옮겨 둡니다.
2. 앱 폴더(`%LOCALAPPDATA%\Programs\ChatCoach`)를 지웁니다. 안의 `data\` 에 내 작업이 있으니 **먼저 확인하세요.**
3. 백업 폴더 `%LOCALAPPDATA%\ChatCoach\` 를 지웁니다(자동 백업, 폴백 데이터).
4. 휴지통을 비웁니다.

새 버전으로 옮길 때 옛 앱 폴더를 지우기 전에 **`data\` 를 새 폴더로 옮겼는지** 꼭 확인하세요.

## 문제가 생기면

- 앱이 갑자기 꺼졌다면 다음에 켤 때 '이전 실행이 비정상 종료되었습니다' 가 뜹니다. 기록은 `data\logs\crash.log` 에 있습니다.
- 일반 기록은 `data\logs\chatcoach.log` 입니다(1MB 씩 최대 4개로 돌려 씁니다).
- 로그에는 채팅 본문·닉네임을 쓰지 않고, 사용자 이름이 든 경로는 `%USERPROFILE%` 로 가립니다. 그래도 문제를 알릴 때는 앱의 **문제 보고 복사** 를 쓰고, 로그 파일을 통째로 공개된 곳에 올리지 마세요.
