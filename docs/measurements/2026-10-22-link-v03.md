# 엔진 link-v0.3(의미 비교) 첫 채점 — 개발 구간 손라벨 30건 (2026-10-22)

숫자만 적는다. 채팅 본문·닉네임·전사문·chat_id 는 적지 않는다. 실제 데이터는 저장소 밖 `chatcoach-data\projects\` 의
두 번째 방송 폴더(`<VOD-B>`, 시범 프로젝트 아님)에 있다. 형식은 [2026-10-21-score-v0.md](2026-10-21-score-v0.md) 를 따른다.

> **과적합 주의.** 이 19분은 v0.2 규칙을 고칠 때도, v0.3 놓친 원인(뜻으로만 이어진 대답)을 찾을 때도 본 구간이다.
> 아래 숫자는 실제보다 좋게 나올 수 있다. v0.3 의 임계값은 합성 문장으로만 맞췄고 이 구간으로 고치지 않았지만,
> 진짜 성적은 **새 구간의 새 손라벨**(또는 시범 3편 봉인 해제 뒤 최종 세트)로 다시 잰다.

## 4. 해석

- **재현율은 오르고(+2건) 정밀도 하한은 내렸다(엔진만 +8건).** 의미 비교가 '높음' 을 더 많이 내는 쪽으로 움직였다. 새 '엔진만'
  8건이 실제 반응인지는 손라벨이 전수가 아니라 모른다(06 6-4).
- **직접 반응 판정은 그대로다.** 의미만으로는 강한 증거를 만들지 않는 설계대로, 직접 18건은 변하지 않았다.
- **반응 시각 오차는 조금 넓어졌다.** 새로 잡은 2건의 시각 차가 큰 쪽이라 90분위가 4.9초 → 6.5초로 늘었다.
- **속도.** 19분 범위(채팅 874건)에서 v0.3 는 v0.2 의 약 5배(8.2초 대 1.6초, CPU, 모델 읽기 1.8초 별도)다. 시간은 범위 안
  채팅 수에 거의 비례하므로, 40분 시범 구간 한 편이면 채팅 밀도에 따라 대략 20초 안팎(+ 모델 읽기)으로 본다.
  파일 전체(채팅 26,261건)를 돌리면 약 50초가 든다.
- 다음: 오탐이 실제로 많은지 보려면 '엔진만' 새 8건을 사람이 보거나(개발 구간 안에서만), 시범 해제 뒤 최종 세트로 v0.2 ↔ v0.3 를
  나란히 보기 '판끼리 견주기' 로 본다. 임계값(answer_min_rel 등)은 그 뒤에 고친다 — 같은 구간으로 고치면 위 숫자는 더 좋아 보이기만 한다.
