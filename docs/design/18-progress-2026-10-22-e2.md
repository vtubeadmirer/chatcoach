### 6-2. F 화면 설계 (클릭 한 번 원칙, D-16)

**열기.** 메뉴 '훈련 → 스트리머 훈련' 한 번. 고르는 창이 없다.
- 열리는 곳: 이 프로젝트에서 사람 최종 세트가 있는 구간의 시작. 구간이 여럿이면 첫 구간.
- 바로 보이는 것: 영상(소리 꺼짐), 흐르는 채팅 패널, 타임라인, 위쪽 '고른 수 n' 하나.
- 최종 세트가 없으면 메뉴가 꺼지고 까닭 한 줄('라벨이 잠긴 구간이 없습니다')만 보인다.

**훈련 중.**

| 동작 | 결과 |
|---|---|
| 채팅 한 번 누름 | '읽겠다' 로 고름(누른 순간의 재생 위치를 함께 적음). 표시가 붙음 |
| 같은 채팅 다시 누름 | 고르기 취소 |
| Space | 멈춤·재생 |
| 구간 끝, 또는 '견주기' 단추 | 견주기 화면으로 |

- 원래 반응 표시·엔진 판정·사람 라벨은 훈련 중에 **보이지 않는다**(정답 미리 보기 방지).
- 입력 칸은 없다. 근거·메모는 받지 않는다.

**견주기 화면.** 열면 바로 표가 보인다.

| 칸 | 내용 |
|---|---|
| 같음 | 내가 골랐고 원래도 반응한 채팅 |
| 나만 | 내가 골랐지만 원래는 반응하지 않은 채팅 |
| 원래만 | 원래 반응했지만 내가 고르지 않은 채팅 |
| 숫자 줄 | 같음 수, 맞힌 비율(같음 / 원래 반응), 고른 시각과 원래 반응 시각의 차 중앙값 |

- 행 한 번 누름 → 그 채팅 시각으로 가서 **소리를 켜고** 원래 대답 앞뒤를 재생한다.
- N / Shift+N 으로 다음·앞 '원래만' 으로 건너뛴다(나란히 보기와 같은 키).
- 채팅 본문은 화면에만 보인다. 기록·내보내기에는 숫자와 chat_id 만(D-17 8).

**소리 끄기의 범위.** 첫 판은 영상 소리를 통째로 끈다(배경음도 같이 꺼짐). 목소리만 빼는 분리는 하지 않는다(새 모델이 필요함).
