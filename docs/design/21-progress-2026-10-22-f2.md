| 메뉴 '훈련 → 시청자 훈련' | **소리 켠** 다시보기(시청자 자리). 실제 채팅이 흐르고, 시나리오가 있으면 가상 채팅도 표시와 함께 섞임 | 2 |
| 쓰기 칸 하나에 채팅을 쓰고 Enter | 그 순간의 VOD 시각으로 보냄. 채팅 패널에 '연습' 표시로 흐름. 재생은 멈추지 않음 | 0 (Enter) |
| 보낸 직후 | 세 축(주제 적합성·대화 확장성·반복 여부)이 칸마다 3단계(좋음·보통·아쉬움)와 까닭 한 줄로 뜸. 합계 점수는 내지 않음 | 0 |
| 구간 끝 | 쓴 수, 축마다 단계 분포, '다른 시청자라면' 예시(retrieved, 가림 이름) 몇 줄 | 0 |
| 닫기 | 작업대로 | 1 |

- 입력 칸은 쓰기 칸 **하나뿐**이다. 점수 고르기·태그 고르기 칸은 두지 않는다(D-19 5).
- 시청자가 쓴 채팅은 시나리오에 '실제' 로 넣지 않고, LLM 입력에도 넣지 않는다(20 6장).

### 6-2. 채점 세 축과 엔진에 필요한 것

| 축 | 첫 판 채점 (AI 없음) | 필요한 것 | 지금 있나 |
|---|---|---|---|
| 주제 적합성 | 보낸 시각 앞 60~120초의 '주제 낱말' 과 쓴 채팅 낱말의 겹침 | (1) 주제 흐름 낱말(VOD 축) | **있음** (엔진 E v0.3 topic-flow) |
| | | (2) 앞 60~120초 **전사문 낱말**. asr.json 은 영상 파일 시각이라 **VOD 보정**이 필요 | **없음.** 엔진 도구가 보정한 '시각별 낱말 파일' 을 미리 만든다(새 엔진 출력) |
| | | (3) 낱말 나누기·정규화 | **있음** (`engine/retrieve.tokens` 를 순수 모듈로 옮겨 같이 씀) |
| | | (4) 의미 비교(e5-small 임베딩) | 엔진 venv 에만(D-17 6). **첫 판은 쓰지 않는다.** 측정 뒤 섞는다 |
| 대화 확장성 | 스트리머가 이어 말할 거리가 있나: 질문 꼴(물음표·의문 어미), 열린 질문(뭐·어떻게·왜) 대 예/아니오, 주제 낱말이 든 구체적인 말, 길이 범위, 이모티콘·'ㅋ' 만이면 낮음 | (1) 한국어 의문 어미·열린 질문 낱말 목록(합성 예문으로 시험) | **없음.** 순수 모듈에 둔다 |
| | | (2) 보정 자료: 실제로 직접 반응을 받은 채팅의 특징 비율 | 최종 세트·손라벨에 있음. **시범은 해제 뒤**, `<P>` 손라벨로 먼저(숫자만) |
| 반복 여부 | (a) 이 훈련에서 내가 앞서 쓴 말과 정규화 뒤 같음·글자 5-gram 겹침 (b) 앞 30~60초 실제·가상 채팅 베끼기 (c) 같은 말버릇 되풀이 | 정규화·5-gram 겹침 | **있음** (retrieve 정규화, 20 8장 5번 `copy_max` 생각을 순수 모듈로) |

- 채점기는 **순수 모듈** ✚ `app/core/viewer_score.py`(표준 라이브러리만, 엔진 import 없음)로 둔다. 엔진은 미리 만든 파일(topic-flow, 시각별 전사 낱말)만 준다. 앱 → 엔진 경계(D-06) 그대로.
- 문턱(겹침 몇 낱말이면 '좋음' 등)은 첫 판 값을 정해 두고 시범 뒤 guide-config 로 옮긴다.

### 6-3. 기록·개인정보·블라인드

| 주제 | 제안 |
|---|---|
| 기록 | ✚ `viewer\<session_id>.jsonl`, 새 `viewer-event` 스키마(줄: start·write·end). label-event·training-event 는 그대로 |
| 쓴 글 저장 | 쓴 글은 사용자 자신의 연습이라 기록 파일에 둔다. 보호 구역(`protected_zone` 에 `viewer/`), 내보내기 안 함. 로그·보고에는 축 단계·숫자만 |
| 시범 | 주제 흐름이 시범에서는 봉인 경로라(D-17 5), 시범 프로젝트는 잠기기 전 메뉴를 끈다 |
| 노출 | 첫 판은 원래 반응·사람 라벨을 보이지 않으므로 노출로 세지 않는다. 보정 자료(6-2)를 화면에 보이기 시작하면 F 처럼 노출로 센다 |
| 사칭 | '다른 시청자라면' 예시는 가림 이름만, 가상 표시를 단다(20 8장 2·3번) |

### 6-5. H-3 은 그 다음
